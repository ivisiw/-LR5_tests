**Тема приложения:** Приложение для просмотра персонажей Rick & Morty.

## Тестирование

### Юнит-тесты (15 тестов, `app/src/test/`)

**`CharacterViewModelTest.kt`** (8 тестов):
- корректное начальное состояние экрана
- успешная загрузка данных
- ошибка загрузки
- retry() после ошибки
- корректная обработка пустого результата (Empty, а не Success с пустым списком)
- загрузка деталей персонажа
- **нетривиальный:** отмена устаревшего запроса при быстром вводе в поиск
- **нетривиальный:** повторное добавление/удаление из избранного не создаёт дублей

**`CharacterRepositoryTest.kt`** (7 тестов):
- корректное преобразование DTO в доменную модель с флагом избранного
- обработка 404 (пустой результат, без исключения)
- обработка прочих HTTP-ошибок (исключение пробрасывается)
- **нетривиальный:** кеш избранных id не запрашивается повторно при пагинации
- удаление из избранного по id
- получение списка избранных с маппингом в модель
- получение персонажа с флагом избранного из базы

### Интеграционные тесты (5 тестов)

**`CharacterRepositoryIntegrationTest.kt`** (3 теста, `app/src/test/`):
- добавление в избранное и считывание из реальной базы Room
- повторное добавление того же персонажа не создаёт дубль
- удаление из избранного реально удаляет запись из базы

**`CharacterListScreenTest.kt`** (2 теста, `app/src/androidTest/`):
- клик по карточке персонажа вызывает переход с верным id (список → детали)
- состояние Error показывает кнопку Retry и её клик вызывает повторную загрузку

Все тесты проходят (`BUILD SUCCESSFUL`).
